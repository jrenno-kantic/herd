# UX Specification

## Philosophy
Inspired by:
- lazygit
- k9s
- vim

## Interaction Model

Modes:
- NORMAL
- COMMAND (:)
- SELECT

## Keybindings

| Key | Action |
|-----|--------|
| j/k | navigate |
| h/l | switch panels |
| :   | command mode |
| enter | execute |
| q | quit |

## Feedback
- instant logs
- visual selection
- status bar
